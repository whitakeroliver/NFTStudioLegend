# NFTStudioLegend

NFTStudioLegend employs an Artificially-intelligent, decentralized hub that integrates real-time data processing with auto-scaling daemon nodes.

With NFTStudioLegend, you get a lightweight tool that stays out of your way.

**What you get**

- NFTStudioLegend employs an Artificially-intelligent, decentralized
- hub that integrates real-time data
- processing with auto-scaling daemon nodes

## Installation

1. Clone the repository: `git clone https://github.com/harutosati/NFTStudioLegend.git`
2. Install required dependencies: `pip install -r requirements.txt`

## Configuration

NFTStudioLegend is configured through environment variables (see `.env.example`). Key options:
- **APP_ENV**: `development` or `production`.
- **PORT**: Port the server listens on.
- **LOG_LEVEL**: `debug`, `info`, or `error`.
